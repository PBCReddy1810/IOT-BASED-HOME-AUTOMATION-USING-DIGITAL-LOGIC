1. SENSOR HIGH-SIDE POWER GATING CIRCUIT (AO3401 P-MOSFET)
--------------------------------------------------------------------------------
                 +3.3V / +5V DC System Rail
                       │
                       ├───[ 100k Pull-up ]───┐
                       │                      │
                       S (Source)             │
                   ┌───────┐                  │
                   │ AO3401│                  │
                   │ P-MOS │                  │
                   └───┬───┘                  │
              Gate ────┤                      │
                       │                      │
                       D (Drain)              │
                       │                      │
                       ├── Gated_VCC (To Sensors VCC)
                       │                      │
                      --- 10uF Tantalum       │
                      --- Capacitor           │
                       │                      │
                      GND                     │
                                              │
ESP32 GPIO 25 ────[ 1k ]──── Gate (2N7002 N-MOSFET)
                             Drain ───────────┘
                             Source ─── GND

Note: When GPIO 25 is HIGH -> 2N7002 turns ON -> Pulls AO3401 Gate to GND -> AO3401 conducts (Gated_VCC = ON).
      When GPIO 25 is LOW  -> 2N7002 turns OFF -> 100k resistor pulls AO3401 Gate to +3.3V -> AO3401 turns OFF (Sensors isolated, 0 uA drain).
